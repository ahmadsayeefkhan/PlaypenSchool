# Image catalogue: frames added since

One row for every crop made with `python build/images.py ... --people ... --shows ...`, in the format of the `img/` table of `image-catalogue.md`; `build/media.py` reads both files. A row is added by the tool, never rewritten by hand. The people column decides what the build allows (see the head of `image-catalogue.md`): `faces` rows are refused until the school has agreed in writing.
